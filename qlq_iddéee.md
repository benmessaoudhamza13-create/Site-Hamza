# Idées de contenu pour le site

## Format
Chaque semaine, publier deux types de revue :
- Une revue macro / marché financier
- Une revue sur un sujet divers (voir idées ci-dessous)

## Idées de sujets d'articles / revues

- Est-ce que les actions sont surévaluées en période de crise ?
